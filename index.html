A repo-level standard, in the spirit of AGENTS.md and CLAUDE.md

ADVERSARIAL_REVIEW.md

Green CI, listening ports, and passing tests are not proof that code is right — they are proof that the code did what its author imagined. AI coding agents make this sharper: they produce plausible, polished output at a pace no human reviewer matches. We need a declared, portable convention for the other half of the loop: systematic adversarial review, performed by agents, against rules the repo itself defines.

The idea

  1. Drop an ADVERSARIAL_REVIEW.md in your repo root.
  2. It tells any coding agent: your work here is expected to survive adversarial review — and here is how that review is done in this repo.
  3. The agent reviews as an adversary, pass by pass, one lens at a time (security, correctness, spec-compliance, performance, abuse, operational), with evidence required for every claim and an explicit per-lens verdict.
  4. You customize the repo-specific section; the protocol stays portable.

Quickstart

curl -O https://adversarial-review.com/ADVERSARIAL_REVIEW.md
# read it, edit the "Repo-specific rules" section, commit

Why not just prompt for it?

  • Persistence. A prompt is forgotten; a file in the repo binds every future session, human or agent.
  • Portability. Any agent that reads the repo conventions (the way AGENTS.md already works) picks it up with zero integration.
  • Accountability. The standard demands evidence-backed, severity-rated findings and explicit "checked and clean" verdicts — the difference between a review and a vibe check.
  • Ownability. The repo declares its own invariants, known weak spots, and required checks. Generic review becomes this codebase's review.

The standard

The canonical template is here, versioned, in this repo:

  • ADVERSARIAL_REVIEW.md — the file you copy into your repo.

Status

v1.0.0 — first public draft. The protocol (lenses, severity taxonomy, evidence rule, output format) is intended to be stable; the template's repo-specific section is yours to change. Feedback and PRs welcome.
